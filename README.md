# ado-board-cli Releases

Official binary releases and distribution repository for **ado-board-cli** — a keyboard-first terminal UI and unified Model Context Protocol (MCP) copilot for Azure DevOps.

- 🌐 **Website**: [https://jagadeesh-k-ti.github.io/ado-board-cli-releases/](https://jagadeesh-k-ti.github.io/ado-board-cli-releases/)
- 📦 **Releases**: [https://github.com/jagadeesh-k-ti/ado-board-cli-releases/releases](https://github.com/jagadeesh-k-ti/ado-board-cli-releases/releases)

---

## 🚀 Quick Install

### Linux & macOS
```bash
curl -sSL https://jagadeesh-k-ti.github.io/ado-board-cli-releases/install.sh | bash
```

### Windows (PowerShell)
```powershell
Invoke-WebRequest -Uri "https://github.com/jagadeesh-k-ti/ado-board-cli-releases/releases/latest/download/ado-board-cli_windows_amd64.zip" -OutFile "ado-board-cli.zip"
Expand-Archive -Path "ado-board-cli.zip" -DestinationPath "$env:LOCALAPPDATA\Programs\ado-board-cli"
```
